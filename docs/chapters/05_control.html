A synthesiser that only does what you tell it, when you tell it, is an instrument. One that also acts on its own is closer to a piece of music. This chapter covers the parts that make things happen in time: the pulsers (clocks), the sequencer (a row of notes), the slew generators (smoothing) and the modulation matrix (patch cables that need no cables).

Pulsers

A pulser is a clock that ticks at a steady rate. There are four, numbered 0 to 3. Each has an on/off switch and a rate in pulses per minute, and both are set on the PULSERS tab. At 60 a pulser fires once a second; at 120, twice. The rate is also a register, PRATE0 to PRATE3 (10 to 600), so a block can change it as it plays: 90 180 50 P ? PRATE1 ! sets pulser 1 to 90 or 180, at random, each time the block runs. Ctrl+P switches all four off and on again without losing their settings.

A pulser does nothing by itself. It fires, and whatever is wired to it responds. Three kinds of thing can be wired:

  • Blocks. Each block has a register, BP0 to BP15, holding a mask: a number whose binary digits say which pulsers run the block. Bit 0 is pulser 0, bit 1 is pulser 1, and so on, so 1 means pulser 0, 2 means pulser 1, and 3 means both. 1 BP0 ! makes pulser 0 run block 0 every time it fires. A block runs once per tick however many pulsers are wired to it and fire together.
  • The sequencer, through SQPUL: each fire moves it one step on (see below).
  • Devices such as the grains (GRPUL), the cellular automaton and the Turing machine (TMPUL), described in Devices.

You can also fire a pulser from code with TRIG: 2 TRIG fires pulser 2 at the next tick. On the desktop, F on the PULSERS tab does the same by hand; on the handheld, the STICKS screen's four buttons do. A key on the KEYS page can fire pulsers too, through KBPUL.

To run a block directly, without a pulser, write its number to RUN: 4 RUN ! runs block 4 at the next tick.

The sequencer

The step sequencer holds eight pitches, SQ0 to SQ7, and plays them in a loop. Each time it is clocked it moves to the next step and does one or two things, which you choose in SQDRV: add 1 to write the step's pitch to PITCH, and add 2 to fire the gate. So 3 does both, which is the usual choice.

  • SQLEN (1 to 8) is how many steps are in the loop.
  • SQEN is a mask of enabled steps, bit n for step n. A disabled step is skipped, which makes rests and shorter patterns easy. If every step is disabled, the sequencer stays where it is.
  • SQSTEP is the current step, 0 to 7.
  • SQCLK: write any non-zero number to clock the sequencer once. SQPUL is the mask of pulsers that clock it.
C4 SQ0 !  E4 SQ1 !  G4 SQ2 !  C5 SQ3 !     \ four notes of a chord
4 SQLEN !                                   \ a loop of four
3 SQDRV !                                   \ set the pitch and play it
1 SQPUL !                                   \ pulser 0 clocks it

With pulser 0 turned on and set to 120, that plays two notes a second, round and round. Pitches are in the units of Pitch, so you can add a semitone offset to a step with ST. Since steps are just registers, a block can rewrite them while the sequence plays.

Slew

Four registers, CV0 to CV3, exist for blocks to write numbers into. They hold -32768 to 32767, can be used as matrix sources, and affect nothing until a route sends them somewhere. A jump in a value is audible as a click or a lurch, so each has a slew: a smoother that makes the change glide. SLT0 to SLT3 set the glide time (1 ms to 5 s; 0 turns the slew off), and the smoothed value appears in SLO0 to SLO3, another matrix source.

The glide is exponential: each step it covers a fixed share of the remaining distance, so it starts fast and finishes slowly, as a real analogue circuit does. This is the way to get a filter to swoop towards a new value instead of jumping.

26000 SLT0 !          \ a glide time of nearly a second
16000 RND CV0 !       \ a random target; SLO0 follows

The modulation matrix

To modulate is to move a setting automatically. The matrix is the switchboard that does it. A route joins a source, something that changes over time, to a destination, a register, with a weight that says how much. Each tick, FEZ computes for every register an effective value:

effective value = the register's own value + (weight ÷ 32768) × the source, then limited to 0 to 32767.

The sound reads the effective value. The register itself is not changed: the CTRL tab shows it, CUTOFF @ reads it, and the sound moves around it. A weight of 32767 passes the whole source, 16384 passes half, and a negative weight turns the source upside down. You can have 16 routes. They are set in the MATRIX tab, or from code with ROUTE:

LFO0 CUTOFF 4000 ROUTE      \ the LFO sways the cutoff
ENV FMAMT 8000 ROUTE        \ each note starts bright
ENV CUTOFF 6000 NEG ROUTE   \ a negative weight

The word takes the source, the destination and the weight, in that order. Routing the same pair again just changes the weight. Any register that shapes the sound can be a destination, except GATE. A full matrix, or an unknown source or destination, is a fault.

A good first route is the one that gives a sound life: send the slow LFO to a cutoff with a small weight. Nothing is added to the code and nothing needs to fire. The sound moves on its own.
