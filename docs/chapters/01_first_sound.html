FEZ is a synthesiser you program. One voice makes the sound; a few lines of a small language, kept in blocks, decide what the voice does and when. You write a line such as C4 PITCH !, press a key, and the note changes. This chapter takes you from switching on to a sound you made yourself.

Start it

On a computer you need a C compiler and the SDL2 library (which draws the window and plays the sound). From the project folder:

make fez
./fez

On the TrimUI Brick, copy the FEZ folder onto the card and start it from the Tools menu; the handheld chapter has the details. The rest of this chapter uses the desktop keys. The Brick's buttons do the same jobs.

The window is cut into three tiles: the editor on the left, a scope (a picture of the sound wave) at top right, and the CTRL list below it. Ctrl+Tab changes the layout, and F1 shows every key on one page. The app starts from a blank patch, which is silent until something plays it.

Load something that plays itself

  1. Press Ctrl+] to move to the PATCHES tab.
  2. Press Right to switch from MY PATCHES to EXAMPLES. The thirteen built-in patches are listed. Typing letters narrows the list.
  3. Pick one with Up and Down and press Enter.

Glass Bells is a good first choice: it plays random bells by itself, using the pulsers (small clocks that start blocks of code, explained in Control). If you hear nothing, press Ctrl+P in case the pulsers are off. The sound is stopped at once with Shift+Esc (mute), which fades the output in 20 milliseconds and leaves everything running.

Play one note

Press Ctrl+G. That fires the gate, which is the on-switch of a note: it opens the envelope (the rise and fall of loudness) once. Press it again and the note repeats. A synthesiser with no keyboard still needs something to say "now", and the gate is that.

Change a number

  1. Press Ctrl+] until you reach CTRL, the list of every register. A register is a named number that the sound reads. CUTOFF is how open the filter is, PITCH is the note, and so on.
  2. Pick CUTOFF with Up and Down.
  3. Press Left and Right to change it (hold Shift for bigger steps), or type a number and press Enter.
  4. Press Ctrl+G after each change and listen.

Nothing here is special to the screen. A register is the same thing whether a person turns it or a line of code writes it. That is how the whole instrument works.

Write a line

Go back to the EDITOR tab (Ctrl+[). The editor holds sixteen blocks; [ and ] move between them. Pick an empty one, and type:

C4 PITCH !
1 GATE !

Read it aloud as "C4, into PITCH; 1, into GATE". The first line sets the note, and the second opens the gate. The ! means "store this number in that register". The next chapter explains why the order is value first, register second.

Typing changes nothing yet. This is deliberate: a half-typed line never alters the sound. Press Ctrl+Enter to apply the block (the editor compiles it and swaps it in), or Ctrl+R to apply it and run it once. Press Ctrl+R: you should hear a C. Change C4 to E4, press Ctrl+R again, and the note moves up four semitones.

If the block has a mistake, the editor says what and where, in red, and keeps the old version running. Try typing -5: it refuses with no negative numbers: write 5 NEG. The language chapter explains why.

Keep it

Press Ctrl+S, type a name, and press Enter. The patch is saved as a plain text file in ~/FEZ/patches/, and appears under MY PATCHES. There is no autosave: a patch you do not save is gone when you quit. Press Ctrl+T to record what you hear to a WAV file in ~/FEZ/recordings/, and Ctrl+T again to stop.
