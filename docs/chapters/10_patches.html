A patch is the whole state of FEZ at one moment: every register, the sixteen blocks and words, the four pulsers, the matrix routes and the devices' settings. Loading a patch replaces all of it, and empties the buffer, the delay, the spring and the compressor, so that nothing from the last patch rings on.

Loading, saving and sharing

On the PATCHES tab there are two lists. MY PATCHES holds the files in ~/FEZ/patches/, and EXAMPLES holds the thirteen that come built in. Left and Right (or [ and ]) switch lists, typing letters narrows the list, Up and Down pick, and Enter loads. Ctrl+S saves the current state under a name, from any tab, and always asks for the name; if the name exists, it asks before overwriting. Ctrl+D or Delete removes a patch, after asking. Ctrl+N throws the current patch away and starts a blank one, from any tab; it asks first, because nothing is saved automatically. On the handheld the same thing is New blank patch on the Menu's MENU tab, and on the PATCHES tab of the Patches screen; answer with A for yes and B for no.

A patch file can also be opened from anywhere when FEZ starts: fez path/to/patch.fez (or fez --brick path/to/patch.fez). It loads as if picked from MY PATCHES; Ctrl+S saves it into ~/FEZ/patches/, not back where it came from. A patch file dragged onto the window loads the same way, and so does a double-click on one in the Finder once the Mac app is installed. On Windows, pick Open with and choose FEZ once. Loading this way replaces the current patch without asking, as picking from the list does.

FEZ never saves by itself. A patch you have not saved is gone when you quit. This is a choice: it means the example you load is always the one you hear, and your own patches change only when you say so.

The patch file

A patch is a plain text file, named after the patch with the ending .fez. You can read it, edit it in any text editor, keep it in version control or mail it to a friend. This is the shape, with comments added here for explanation:

FEZ PATCH 1
name Deep Loop
desc Frippertronics at ambient speed...
listen Soft notes that return minutes later
level 16384                 the master level
pulser 0 on 1 rate 10       number, on or off, pulses a minute
grains 120                  looping grain voices that were playing (bit n is voice n)
reg CUTOFF 12000            a register, by name (only if not default)
reg DLYFB 29000
route ENV CUTOFF 6000       source, destination, weight
ca 30 10836 0 4             automaton: rule, row, tap, trigger
lz 8000 15300 4             Lorenz: rate, rho, trigger
block 0                     its code; lines start "> "
> 3 RND 0 =  1 JZ
> ...
word 2                      the same for a word

Only registers that differ from the defaults are written, so a file stays short, and registers are stored by name, so a patch keeps working if a register ever moves. Blank lines and lines beginning with # are ignored. A line FEZ does not understand is skipped, and the patch loads without it; the status bar says how many were skipped. A file that is not a patch at all is refused.

What is not saved is whatever is only in motion: the audio in the buffer, the position of the sequencer, the phase of the LFO and the envelope. Looping grains that were playing are the exception: they start again on load, though over an empty tape until something records. A patch starts from rest, as the built-in ones do.

Making your own

Start from the blank patch, which is what FEZ loads at first, or from one of the examples, and change one thing at a time. A good order is:

  1. Make one note you like with the CTRL tab: pitch, wave, filter, envelope.
  2. Write a block that plays it, and apply and run it with Ctrl+R.
  3. Wire the block to a pulser: Ctrl+1 in the editor, and switch the pulser on and set its rate on the PULSERS tab.
  4. Add one moving thing: a matrix route from the LFO or the envelope.
  5. Add space: the delay and the spring.
  6. Save it with Ctrl+S.

For a patch that plays itself for an hour, build it as Deep Loop does: few notes, long envelopes, and the delay doing most of the work.
