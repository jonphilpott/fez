FEZ comes with fourteen patches, built in and listed under EXAMPLES on the PATCHES tab. Each one is meant to show something. Load one, listen, then open the editor and read its blocks. This chapter lists them and takes three apart.

Three of them, line by line

Glass Bells

One block, run by pulser 0. Each time it runs it chooses a random note and plays it:

\ bell: random degree 0..9 of colour 10 over C3
10 RND 10 COLOUR C3 + PITCH !
6000 RND 4000 + FMAMT !
1 GATE !
  • 10 RND picks a whole number from 0 to 9. 10 COLOUR turns it into a note of the minor pentatonic scale: 0 to 4 are the first octave, 5 to 9 the next. The result is a distance above the root.
  • C3 + adds the root. PITCH ! stores the pitch.
  • 6000 RND 4000 + is a random number from 4000 to 9999, stored as the FM depth, so each bell has a slightly different brightness.
  • 1 GATE ! plays it.

The patch also has a matrix route that sends the envelope to FMAMT (see the matrix), so the bell starts bright and mellows, and a second block, run by pulser 1, that changes the amount of delay now and then.

Rule 30 Rain

\ block 0 (pulser 0): reseed if dead, then step
CACOUNT @ 1 JNZ  0x0100 CAROW !  1 L
1 CASTEP !
  • CACOUNT @ is the number of living cells. 1 JNZ jumps to label 1 if it is not zero, skipping the reseed. If the automaton has died out, 0x0100 CAROW ! puts a single live cell in the row to start again.
  • 1 L is label 1, and 1 CASTEP ! then runs one generation.
\ block 1, run by pulser 1 on every birth at the watched cell
CAROW @ 7 AND 13 COLOUR C3 + PITCH !
CACOUNT @ 10 SHL FMAMT !
1 GATE !
  • CAROW @ 7 AND keeps the low three bits of the row: a number from 0 to 7. 13 COLOUR C3 + turns it into a pentatonic note.
  • CACOUNT @ 10 SHL is the number of live cells times 1024: the more crowded the row, the more FM.
\ setup, run once: tap cell 3; a birth fires pulser 1
3 CATAP !  1 CATRIG !  30 CARULE !

Deep Loop

The patch is described in a tape-loop patch, step by step. Its three blocks are:

\ block 0: a low note, one time in three
3 RND 0 =  1 JZ
  5 RND 13 COLOUR  C2 8 ST + +  PITCH !
  1 GATE !
1 L
  • 3 RND 0 = is true one time in three (when the random number is 0). 1 JZ jumps to the end, doing nothing, the other two times in three. So this block plays rarely.
  • The note is a pentatonic note over C2, plus 8 ST: eight semitones, which lifts the root to A flat.
\ block 2: let the loop breathe, one time in four
4 RND 0 =  1 JZ
  16000 RND 6000 +  DLYIN !
1 L

This one picks a new input level for the delay, from 6000 to 21999, so the loop slowly swells and thins. Block 1 is the same as block 0 but one octave higher and one time in four.
