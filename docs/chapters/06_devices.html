A device is a small machine inside FEZ that produces change by itself. It has no sound of its own. It makes numbers: a row of bits that evolves, a curve that never repeats, a melody that drifts. You use those numbers by routing them through the matrix, reading them in a block, or letting a device fire a pulser when something happens. Each device has a page on the DEVICES tab (move between pages with [ and ]).

Here is the idea behind all of them. A sound that is perfectly steady is dull, and one that is perfectly random is noise. Music lives in between: patterns that nearly repeat. The devices are different ways of producing that.

Cellular automaton

Picture a row of 16 cells, each on or off, joined in a ring. At each generation every cell looks at itself and its two neighbours, which gives three bits, or a number from 0 to 7. A rule says what the cell becomes for each of the eight patterns. The rule is itself a number from 0 to 255, one bit for each pattern, and it is held in CARULE. Rule 30 produces a tangled, unpredictable-looking pattern from almost nothing, and rule 90 draws triangles. The row is CAROW, one bit per cell.

  • CASTEP: write a number from 1 to 16 to run that many generations. 1 CASTEP ! runs one. On the DEVICES page, Space does it.
  • CATAP picks one cell to watch (0 to 15) and CABIT reads its state.
  • CATRIG picks a pulser (0 to 3) to fire when the watched cell is born, which means it was off and is now on. 4 means none.
  • CACOUNT is the number of live cells, and CADENS is the same as a proportion, for the matrix. Both are read only.

A worked example: pulser 0 runs one generation every beat, and each birth at the watched cell fires pulser 1, which plays a note picked from the low four bits of the row. The notes come from a pentatonic colour, so they sound right together.

\ block 0, run by pulser 0: advance the automaton
1 CASTEP !
\ block 1, run by pulser 1: play a note from the row
CAROW @ 15 AND 13 COLOUR C3 + PITCH !
1 GATE !
\ any block, run once: wire it up
1 BP0 !         \ pulser 0 runs block 0
2 BP1 !         \ pulser 1 runs block 1
1 CATRIG !      \ a birth fires pulser 1

Turn pulser 0 on at 120 pulses a minute. COLOUR turns a number into a note of a five-note scale: the first number steps up the scale, and the second chooses the flavour, 0 to 15. The word reference explains it in full.

Lorenz attractor

The Lorenz attractor is three numbers that chase each other according to three equations from a weather model of 1963. The path they trace never repeats, but it stays within bounds and loops lazily round two lobes, like a butterfly's wings. That makes it a good slow, smooth, unpredictable modulator.

  • LZX, LZY and LZZ are the three values, read only. All three are matrix sources.
  • LZRATE sets the speed.
  • LZRHO sets a parameter of the equations. About 28 gives the classic chaotic path; lower values make the path settle towards a fixed point instead of wandering.
  • LZTRIG picks a pulser to fire each time X crosses zero, which is each time the path swaps lobes. 4 means none.
  • LZSEED: write any number to restart the path from a new place.
LZX CUTOFF 6000 ROUTE        \ the filter wanders
LZZ FOLD 4000 ROUTE

Quantiser

To quantise is to round to the nearest allowed value. The quantiser rounds the pitch to the nearest note of a scale. That is how a wandering signal, such as an LFO or the Lorenz attractor, can control a pitch and still sound like music.

  • QON: any non-zero number turns it on.
  • QSCALE chooses the scale: 0 chromatic, 1 major, 2 natural minor, 3 dorian, 4 major pentatonic, 5 minor pentatonic, 6 blues, 7 whole tone.
  • QROOT is the note the scale is built on, written like a pitch: C3 QROOT !.

It works on the pitch the voice hears, after the matrix adds its modulation. It does not touch the PITCH register. So the register can hold any number and the sound still lands on the scale. A note exactly between two scale notes goes to the lower.

1 QON !
4 QSCALE !                   \ major pentatonic
C3 QROOT !
LFO0 PITCH 3000 ROUTE        \ an octave each way, in key

Turing machine

This is a loop of bits that rewrites itself slowly. It holds up to 16 bits in a ring. At each step the oldest bit is taken, flipped with some chance, and put back in as the newest. If the chance is 0, nothing is ever flipped and the pattern repeats exactly. If it is high, the pattern is random. In between, a melody emerges that nearly repeats and changes a little each time round.

  • TMLEN: how many bits are in the loop, 2 to 16. The loop length is the length of the repeating phrase.
  • TMCHANCE: the chance that a bit flips. 0 never; 16384 is a coin toss (fully random); the default 4096 is about one in eight.
  • TMSTEP: write any non-zero number to take a step. TMPUL is a mask of the pulsers that step it.
  • TMBITS: the bits themselves. Writing sets them.
  • TMOUT: the newest eight bits (or all, if the loop is shorter) read as a number, 0 to 32767. It is a matrix source.
1 TMPUL !                    \ pulser 0 steps the machine
TMOUT PITCH 6000 ROUTE       \ the bits pick the pitch
1 QON !  4 QSCALE !          \ keep it in key

Lock the pattern by setting 0 TMCHANCE !, and loosen it a little at a time.

Keyboard

The keyboard device turns key presses into notes. On the desktop, the KEYS tab plays the computer keyboard like a piano: the bottom row (Z S X D C V G B H N J M) is one octave, and the row above (Q 2 W 3 E R 5 T 6 Y 7 U) is the next. The layout follows the position of the keys, so it works on any national layout. Only that tab plays, and Space lets go of everything. The handheld has no KEYS tab; its STICKS screen plays the keyboard device from the left stick instead (see the handheld chapter).

A key press does four things: it writes the note into PITCH and KBNOTE, fires the gate, fires the pulsers in the mask KBPUL, and holds the gate open until the key is let go, then the release runs. If you press a second key while the first is held, the new one wins, and letting go of it returns to the first without a new attack. KBOCT (0 to 8) is the octave of the bottom key, and KBGATE is 1 while any key is down. KBNOTE and KBGATE are read only; KBNOTE is also a matrix source, which can be used to make a filter follow the notes you play.

KBNOTE CUTOFF 2000 ROUTE     \ higher notes sound brighter

Colour mode. With KBTYPE at 1 (TYPE on the KEYS tab), the white keys play a colour instead of every semitone: KBCOL (0 to 15, the same colours as the word COLOUR) picks which. Z X C V B N M are its first seven steps, starting from KBROOT (ROOT on the tab: any note, C3 unless you change it), and Q W E R T Y U carry on from the eighth, so a five-note colour reaches past the octave. KBOCT only moves the keys in chromatic mode. A block can change KBROOT or KBCOL while you play, to move the keyboard to a new key or colour under your hands. The black keys are silent. Colours are tuned in just intervals, so the notes fall between the piano's: PITCH gets the exact pitch, and KBNOTE the nearest whole note. MIDI notes always play every semitone.

Swell mode. With KBMODE at 1 (MODE on the KEYS tab), a key plays no note. It sets PITCH, with no attack, and while any key is held GATELEVEL opens, taking KBSWELL milliseconds (50 to 4000, default 1000) to open fully; once every key is up it closes over the same time. Holding a key longer makes the note louder and brighter, like a bowed string or a swell pedal. Pressing a new key while one is held changes the pitch and keeps the swell open. It works with colour mode too.

The swell is also a matrix source, SWELL: route it to CUTOFF, FOLD or DLYIN and they open with it, so a held key brightens the sound or feeds the echo as well as making it louder. It reads GATELEVEL, so it follows the STICKS tab's swell on the handheld too, and anything a block writes there. In code: GATELEVEL CUTOFF 8000 ROUTE.
